# Comparison results

Everything in this folder is generated by `system/evaluation/` from the root of
the repository (the figures of the report, `memoria/memoria.tex`, are read from here).

| File | Contents | Generated by |
|---|---|---|
| `tabla_resultados.md` / `.csv` | FD-MNIST, % recognizable, entropy, ms/image and speed-up of each model and number of steps | `compare.py` + `reuse_timing.py` |
| `resultados.json` | The above plus the per-digit distribution of each configuration | `compare.py` + `reuse_timing.py` |
| `calidad_vs_nfe.png` | FD-MNIST and % recognizable against network evaluations | `compare.py` |
| `distribucion_digitos.png` | Heatmap of the digits predicted by the classifier | `compare.py` |
| `muestras_ve.png`, `muestras_rf.png` | Samples from the VE and RF families: 10 rows (same noise per row), one column per model and number of steps | `compare.py` |
| `muestras_ve_3filas.png`, `muestras_rf_3filas.png` | Compact version (3 rows, columns chosen in `GRID_3ROWS`) used in the report | `compare.py` |
| `muestras_ve_sin_ema.png` | VE teacher and CM-VE (CD) with and without EMA in the teacher (5 rows, columns in `NOEMA_GRID`); this is the ablation of the appendix | `compare.py` |
| `tiempo_vs_n.png` | Generation time against the number of images | `reuse_timing.py` |
| `tiempos_referencia.json` | Times measured once on an idle CPU; time only depends on the network and the number of evaluations, so they are shared between models of the same kind | measured once |
| `variabilidad_ruido.md` / `.csv` | Mean and standard deviation of the metrics of the consistency models over 5 noise seeds (same trained model) | `seed_variance.py` |
| `cm_rf_pesos_teacher.md` / `.csv` | CM-RF distilled from the EMA weights and from the raw weights of the 1-RF | `cm_rf_teacher_weights.py` |

Order to regenerate everything:

```
python system/evaluation/compare.py --no-timing   # ~17 min on CPU
python system/evaluation/reuse_timing.py          # reference timings
python system/evaluation/seed_variance.py         # ~15 min
python system/evaluation/cm_rf_teacher_weights.py
```

Consistency models are compared with the teacher they were distilled from: CM-VE
(CD) with the `VE teacher` (EMA weights, `checkpoints/mnist_all_ve_ema.pth`), CM-RF
with the 1-RF and CM-RF (reflow) with the 2-RF. CT and iCT have no teacher.

CM-VE (CD) was trained with
`python system/training/consistency_distillation_training.py --teacher ve --teacher-tag ema --tag ema`
and is saved in `checkpoints/mnist_all_cm_ve_ema.pth`.

Ablation (only in the appendix of the report): `VE teacher (no EMA)` is the first VE
teacher (40 epochs, constant lr, no EMA) and `CM-VE (CD, no-EMA teacher)` is the CM-VE
distilled from it. They appear in `tabla_resultados` and in `resultados.json`, but not
in the main figures (`calidad_vs_nfe.png`, `muestras_ve*.png`,
`distribucion_digitos.png`), only in `muestras_ve_sin_ema.png`. `CM-VE (iCT v1)` and
`CM-VE (iCT v1, stage 1)` appear in the complete table and in `muestras_ve.png`, but
not in `calidad_vs_nfe.png`.

Consistency training models (no teacher):

| Model | Checkpoint | Training |
|---|---|---|
| CM-VE (CT v1) | `checkpoints/mnist_all_cm_ve_ct.pth` | `system/training/consistency_training.py` |
| CM-VE (CT v2) | `checkpoints/mnist_all_cm_ve_ct_v2.pth` | `system/training/consistency_training_v2.py` |
| CM-VE (iCT v1) | `checkpoints/mnist_all_cm_ve_ict_n640.pth` | `consistency_training_improved.py` (phase 1, saves `mnist_all_cm_ve_ict.pth`) and `consistency_training_improved.py --init-from ./checkpoints/mnist_all_cm_ve_ict.pth --s0 160 --s1 640 --batch-size 128 --lr 2e-4 --iterations 32289 --tag n640` (phase 2) |
| CM-VE (iCT v2) | `checkpoints/mnist_all_cm_ve_ict_40k_ema_lrconst.pth` | `consistency_training_improved.py --iterations 40000 --sample-ema 0.9995 --constant-lr --tag 40k_ema_lrconst` |

`variabilidad_ruido` includes all the consistency models (also the CD without EMA),
measured in a single run with the same seeds. If `compare.py` or `seed_variance.py` are
run again with another order or set of models, the multistep rows change slightly,
because that sampling uses the global generator.

The RF ablation figures (EMA against raw, 1-RF against 2-RF, tau sweep) are in
`figures/`.
